## What is optimal prompt queue design in generative AI?

**Optimal prompt queue design** is the systematic practice of structuring batch sizes (typically 15 to 30 scenes per run), spacing submissions with natural human jitter, establishing clear retry thresholds, and utilizing consistent prompt syntax to prevent cloud rate limits and sequence corruption.

Poorly structured queues risk tripping platform abuse heuristics or entering endless failure loops. Following disciplined queue design standards ensures reliable, unattended execution.

---

## 1. Optimal Batch Sizing (The Rule of 25)

While it may be tempting to paste 200 prompts into a single queue, cloud generative AI platforms are not designed for unbroken marathon sessions. Browser memory accumulates DOM nodes, WebSockets can drop, and cloud allocation quotas tighten after prolonged continuous activity.

**Best Practice:**
- Divide large projects into modular **batches of 20 to 30 prompts**.
- Execute each batch in Safe Sequence Mode.
- Review and export completed assets before queuing the next scene set.

---

## 2. Setting Intelligent Retry Thresholds

Flowmator allows configuring auto-retries between 0 and 5:

- **0 Retries:** Halts immediately on any error. Recommended when testing new, risky prompt vocabulary where you want to inspect moderation triggers immediately.
- **2 Retries (Recommended):** The optimal balance. Clears transient cloud network hiccups and brief 10-second token bucket throttles without wasting time on persistent keyword rejections.
- **5 Retries:** Only recommended during known cloud infrastructure degraded performance windows.

---

## 3. Delimiter Hygiene: Avoiding Common Syntax Bugs

When parsing prompts from external scriptwriters or spreadsheets:
- **Avoid Trailing Blank Lines:** Blank lines at the end of a prompt document can be parsed as empty queue items.
- **Escape Internal Quotation Marks:** In CSV files, ensure dialogue quotation marks are properly escaped (`""she said""`) to prevent premature cell termination.
- **Use Distinct Scene Identifiers:** Prefix each prompt with its scene and shot number (`01_A`, `01_B`). This makes tracking progress in the side panel immediate and intuitive.
